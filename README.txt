OPEN CITY 3D - Android APK project
Features included: mobile touch controls, on-foot movement, vehicle driving, wanted level,
money HUD, missions, city/buildings/trees, and basic firing/wanted interaction.

Build:
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. Install the generated app-debug.apk on your Android phone.

Note: This is an original GTA-style prototype, not GTA 5 assets or code.
